# 💗 Chá de Panela

Site feito em React + Vite para organizar o cadastro de convidados de um chá de panela (ou chá de casa nova).

## Páginas

- **Home** — apresentação do evento (data, local e como ajudar).
- **Cadastrar** — formulário com nome, email, telefone e o que a pessoa vai levar.
- **Convidados** — lista todos os cadastros já feitos.
- **Sugestões** — ideias de presentes organizadas por categoria.
- **Perguntas** — perguntas frequentes sobre o evento.

Os cadastros são salvos no `localStorage` do navegador, então não é necessário rodar nenhum servidor além do próprio Vite.
